# Australian Native Birds — FIT3179 Data Visualisation 2

Interactive data visualisation exploring the distribution,
observations, diversity and conservation of Australian native birds.

## Project structure

- `index.html` — main webpage
- `css/` — webpage styling
- `js/` — Vega-Lite visualisation specifications
- `data/` — datasets used by the visualisations
